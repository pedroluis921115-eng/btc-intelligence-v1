- **ANÁLISIS:** contexto 4H/1H/15M/5M, zonas, flujo, funding, información importante y ahora **agenda de eventos importantes de 7/14 días (macro + resultados de tecnológicas)**, con horarios en Curitiba y avisos de datos prioritarios de EE. UU.

No está demostrado que ningún gráfico, confluencia o evento prediga la dirección o rentabilidad de BTC. Valida fechas definitivas y no operes impulsivamente alrededor de datos muy importantes.
